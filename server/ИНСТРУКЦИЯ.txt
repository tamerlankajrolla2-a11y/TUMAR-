РЕСТОРАН «ТУМАР» — БАЗА И АДМИНКА НА SUPABASE
=============================================

Сайт (index.html) и админка (admin.html) лежат на GitHub Pages.
База и вход в админку — в Supabase (бесплатно). Отдельный сервер не нужен.

1. ПРОЕКТ
   supabase.com → New project → имя: tumar → пароль базы: «Сгенерировать»
   (сохраните себе, никому не отправляйте) → регион Frankfurt → Create.

2. БАЗА
   Слева SQL Editor → New query → вставить весь текст supabase.sql → Run → «Success».

3. АДМИНИСТРАТОР
   Authentication → Users → Add user → Create new user:
     Email: любая почта (например, ваша)
     Password: пароль от админки
     галочка Auto Confirm User → Create user.
   Затем Authentication → Sign In / Providers → выключить «Allow new users to sign up»
   (чтобы посторонние не могли зарегистрироваться).

4. КЛЮЧИ
   Project Settings (шестерёнка) → API / API Keys:
     Project URL  — https://xxxx.supabase.co
     anon (publishable) key — длинная строка
   Их можно вписывать в сайт: они публичные, защиту дают правила в базе.
   service_role / secret key и пароль базы — НИКОМУ и никуда.

5. ПОДКЛЮЧЕНИЕ
   В index.html (блок «НАСТРОЙКИ») вписать sbUrl и sbKey,
   в admin.html (строка const CFG) — sbUrl, sbKey и email администратора.

АДМИНКА: https://tamerlankajrolla2-a11y.github.io/TUMAR-/admin.html
Вход — только пароль. Что умеет:
  • Заявки с сайта (банкет / столик, блюда и сумма), подтвердить / отменить, заметки,
    кнопки «Позвонить» и WhatsApp. Подтверждённый банкет закрывает дату на сайте.
  • Календарь, «Закрыть дату», «Бронь вручную», выгрузка в Excel.
  • «Меню и цены»: цены, названия, новые блюда, «Нет сегодня», «Фирменное».
  • «Объявление» — красная строка над сайтом.
