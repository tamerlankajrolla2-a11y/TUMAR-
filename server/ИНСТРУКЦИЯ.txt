РЕСТОРАН «ТУМАР» — СЕРВЕР НА CLOUDFLARE
=======================================

Сайт (index.html) и админка (admin.html) лежат на GitHub Pages.
Заявки, календарь, меню и вход в админку — на отдельном сервере в Cloudflare:
Worker «tumar-api» + база D1 «tumar». Старый вариант на Supabase отключён
(бесплатные проекты Supabase засыпают через 7 дней без запросов).

Адрес сервера: https://tumar-api.tamerlankajrolla2.workers.dev

ЧТО ГДЕ
  server/worker.js — код сервера (в нём вместо хэша пароля стоит __ADMIN_HASH__)
  Cloudflare → Workers & Pages → tumar-api → Settings → Bindings: DB = база «tumar»
  Таблицы создаются сами при первом запросе: заявки, закрытые даты, меню/объявление.

ПАРОЛЬ АДМИНИСТРАТОРА
  Вход только по паролю. Сменить можно в админке: вкладка «Объявление» → «Пароль администратора».

ЕСЛИ СЕРВЕР НУЖНО ПЕРЕСОЗДАТЬ
  1. Cloudflare → Storage & databases → D1 → Create → имя tumar.
  2. Workers & Pages → Create → Hello World → имя tumar-api → Deploy → Edit code →
     вставить server/worker.js, вместо __ADMIN_HASH__ — sha256 от «tumar:пароль» → Deploy.
  3. Settings → Bindings → Add binding → D1 database → имя DB → база tumar.
  4. В index.html и admin.html (блок «НАСТРОЙКИ» / const CFG) указать адрес Worker в api.

АДМИНКА: https://tamerlankajrolla2-a11y.github.io/TUMAR-/admin.html
  • Заявки с сайта (банкет / столик, блюда и сумма), подтвердить / отменить, заметки,
    кнопки «Позвонить» и WhatsApp. Подтверждённый банкет закрывает дату на сайте.
  • Календарь, «Закрыть дату», «Бронь вручную», выгрузка в Excel.
  • «Меню и цены»: цены, названия, новые блюда, «Нет сегодня», «Фирменное».
  • «Объявление» — красная строка над сайтом. Смена пароля.
