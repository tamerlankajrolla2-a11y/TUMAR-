САЙТ РЕСТОРАНА «ТУМАР» — КАК ЗАПУСТИТЬ
======================================

Файлы:
  index.html  — сайт (выкладывается на GitHub Pages, один файл — всё внутри: фото, видео, шрифты)
  worker.js   — сервер + админ-панель (Cloudflare Worker)
  schema.sql  — таблицы базы данных (Cloudflare D1 — это SQLite в облаке)

Сайт работает сразу, даже без сервера: заявки на бронь и заказы уходят
администратору в WhatsApp (+7 777 595 87 96). Сервер нужен, чтобы заявки
сохранялись в базе, в календаре были видны занятые даты, а у ресторана была
админка с меню и ценами.

Всё как у Эмирата, шаги те же.


1. БАЗА ДАННЫХ (2 минуты)
-------------------------
1) dash.cloudflare.com → «Storage & Databases» → «D1 SQL Database» → «Create».
2) Название: tumar → «Create».
3) Откройте базу → вкладка «Console» → вставьте весь текст из schema.sql → «Execute».


2. СЕРВЕР (WORKER)
------------------
1) «Workers & Pages» → «Create» → «Create Worker» → имя: tumar-booking → «Deploy».
2) «Edit code» → удалите всё → вставьте весь текст из worker.js → «Deploy».
3) Worker → «Settings» → «Bindings» → «Add» → «D1 database»:
     Variable name: DB      Database: tumar      → «Save».
4) Worker → «Settings» → «Variables and Secrets» → «Add»:
     Type: Secret   Name: ADMIN_PASSWORD   Value: придумайте надёжный пароль → «Save».
   Этот пароль — для входа в админку (его получает ресторан).
5) Скопируйте адрес Worker'а — вида https://tumar-booking.ВАШ-АККАУНТ.workers.dev


3. ПОДКЛЮЧИТЬ САЙТ К СЕРВЕРУ
----------------------------
В index.html найдите поиском   api: '',
и впишите адрес Worker'а:      api: 'https://tumar-booking.ВАШ-АККАУНТ.workers.dev',
Сохраните и загрузите index.html на GitHub Pages.

Проверка: откройте сайт → «Даты и бронь» → у дней в календаре появится «свободно».
Внизу сайта появится ссылка «Вход для администратора».


4. АДМИНКА ДЛЯ РЕСТОРАНА
------------------------
Адрес: https://tumar-booking.ВАШ-АККАУНТ.workers.dev/admin  (+ пароль из пункта 2.4)
На телефоне: открыть в браузере → «Добавить на главный экран» — будет как приложение.

Что умеет:
  • Заявки с сайта: банкет или столик, дата, гости, праздник, блюда, которые гость
    выбрал на сайте, и их сумма. Кнопки «Позвонить» / WhatsApp, заметки.
  • «Подтвердить» банкет — дата на сайте сразу становится «занято».
    Подтверждённый столик дату не закрывает.
  • Календарь месяца: банкеты, столики, новые заявки, закрытые дни.
  • «Закрыть дату» — для брони по телефону, своего мероприятия, выходного.
  • «Бронь вручную» — внести заказ, принятый по телефону.
  • «Меню и цены» — менять цены и названия, добавлять и удалять блюда,
    отмечать «Нет сегодня» (блюдо станет серым) и «Фирменное».
    После «Сохранить» сайт обновляется сразу. «Вернуть исходное меню» — откат.
  • «Объявление» — красная строка над сайтом (например, «31 декабря работаем до 17:00»).
  • «Excel» — выгрузка всех заявок в таблицу.


ГДЕ ЧТО ПОМЕНЯТЬ В index.html (если нужно)
------------------------------------------
В начале скрипта, блок «НАСТРОЙКИ»:
  wa:  '77775958796'   — номер WhatsApp, куда идут заявки и заказы
  phone / phone2       — номера для кнопок «Позвонить»
  address, hours       — адрес и время работы для помощника


НЕОБЯЗАТЕЛЬНО
-------------
• ALLOWED_ORIGIN (Variable) = адрес сайта, например https://ИМЯ.github.io —
  тогда отправлять заявки сможет только ваш сайт.
• Уведомления в Telegram о каждой новой заявке: создайте бота у @BotFather и добавьте
  секреты TG_TOKEN (токен бота) и TG_CHAT_ID (ID чата администратора).

Бесплатного тарифа Cloudflare хватает с большим запасом: 100 000 запросов в день и 5 ГБ базы.
